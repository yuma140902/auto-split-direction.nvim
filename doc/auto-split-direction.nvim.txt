==============================================================================
INTRODUCTION                          *auto-split-direction.nvim*

auto-split-direction.nvim provides a command that chooses a window split
direction from the dimensions of the current window.

If the window width is greater than its height multiplied by the configured
ratio, the plugin creates a vertical split. Otherwise, it creates a horizontal
split.

==============================================================================
COMMANDS                              *auto-split-direction.nvim-commands*

                                               *:SplitAutoDirection*
:SplitAutoDirection
        Splits the current window in the direction selected from its width,
        height, and the configured ratio.

==============================================================================
LUA API                               *auto-split-direction.nvim-api*

setup({opts})                         *auto-split-direction.setup()*
        Configures the plugin and creates |:SplitAutoDirection|.

        {opts} may contain:

        debug     (boolean) Show debug messages. Default: false.
        ratio     (number)  Width-to-height threshold used to choose the split
                           direction. Default: 3.0.

auto_split({ratio}, {debug})          *auto-split-direction.auto_split()*
        Splits the current window vertically when its width is greater than
        its height multiplied by {ratio}. Otherwise, splits it horizontally.
        When {debug} is true, displays the current window dimensions.
